# Sistema de Doação de Alimentos

Sistema desktop para gerenciamento de doações de alimentos não perecíveis, desenvolvido para uma atividade extensionista do curso de CST em Análise e Desenvolvimento de Sistemas.

O projeto está relacionado ao **ODS 2 – Fome Zero e Agricultura Sustentável** e tem como objetivo utilizar a tecnologia como apoio ao cadastro e gerenciamento de doações de alimentos.

## Funcionalidades

- Cadastro de doações
- Consulta de doações por ID, nome ou todos os registros
- Edição de doações
- Exclusão de doações
- Relatório das doações cadastradas
- Exibição do total de doações e itens doados
- Identificação do alimento mais doado

## Tecnologias utilizadas

- Python
- PySide6
- SQLite
- Qt Designer

## Como executar

Instale as dependências do projeto:

```bash
poetry install
```

Execute a aplicação:

```bash
python -m src.main
```
